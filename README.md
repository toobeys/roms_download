## Fitur

- 16 judul game NES.
- Cover otomatis dari GitHub.
- Desain retro gaming neon.
- Search game.
- Responsive desktop, tablet, dan HP.
- Fallback jika gambar tidak ditemukan.

## Cara Instalasi

1. Buka repository:
   https://github.com/toobeys/roms_download

2. Upload index.html ke direktori utama.

3. Upload README.md ke direktori utama.

4. Pastikan seluruh gambar berada di folder images.

5. Aktifkan GitHub Pages:
   Settings → Pages.

6. Pilih branch main dan folder root.

7. Klik Save.

## Cover yang Belum Tersedia

Super Mario Bros. 25th Anniversary.

Jika cover sudah tersedia, ubah properti image:null
di dalam data game pada index.html menjadi nama file
gambar yang sesuai.

## Catatan

Halaman ini merupakan katalog gambar dan tidak
menyimpan file ROM. Pastikan file game yang
didistribusikan memiliki izin yang sesuai.
