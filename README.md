TOOBEY — ROMS NES - Favorite
Halaman katalog game NES bergaya retro-neon untuk proyek TOOBEY.
Isi folder
`index.html` — halaman katalog mandiri, responsif untuk desktop dan HP.
`README.md` — panduan penggunaan dan publikasi.
Fitur
Desain retro gaming dengan aksen neon.
Kartu katalog untuk 16 judul game.
Pencarian berdasarkan judul atau wilayah.
Layout responsif untuk desktop, tablet, dan HP.
Tidak membutuhkan library eksternal atau backend.
Menjalankan secara lokal
Ekstrak folder ZIP.
Buka `index.html` menggunakan browser.
Halaman berjalan langsung tanpa instalasi.
Publikasi ke GitHub Pages
Letakkan folder `nes-favorite` di repository landing page TOOBEY. Contoh struktur:
```text
/
├── index.html
└── nes-favorite/
    ├── index.html
    └── README.md
```
Tautan kembali di katalog sudah diarahkan ke `../index.html`. Dari landing page utama, tambahkan tautan ke `nes-favorite/`.
Tentang tautan unduhan
File ini dibuat sebagai katalog judul, bukan penyedia file ROM. Tautan unduhan yang dikirim sebelumnya tidak dimasukkan. Tambahkan tombol unduh hanya untuk game homebrew, domain publik, atau file yang memang memiliki izin distribusi yang jelas.
